# /public/projects

Images and screenshots for individual projects.

- Organise by project slug, e.g. `public/projects/example-project/cover.png`.
- Reference from project metadata as `/projects/<slug>/<file-name>.<ext>`
  (see `coverImage` in `src/types/project.ts`).
- Keep images reasonably compressed — prefer `.webp` or optimised `.png`/`.jpg`.
