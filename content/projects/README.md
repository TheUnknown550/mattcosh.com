# Project Content (MDX)

Each file here is a long-form case study for one project, matched by slug to
an entry in `src/data/projects.ts`.

- File name must match the project's `slug` field: `<slug>.mdx`.
- Metadata (title, tech stack, links, etc.) lives in `src/data/projects.ts`,
  not here — these files are for prose only.
- See `docs/content-management.md` for the full convention.
